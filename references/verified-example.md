# 已验证的起点

2026-09-26 本地工程 `Parallax-Ink-Handoff/work-v2` 用五张 AI 生成肖像制作了 36 秒 1080×1920、30 fps、H.264/AAC 的成片；用前三人制作了 15 秒 720×1280 预览；用一张独立生成的彩色猫插画构建了 10.4 秒视频。浏览器验证了固定物体、同一时刻确定性、独立层显示、播放/跳转/拖动与离线加载。单图猫和两图混合输入也通过了 HTML 启动与关键帧检查。

这些是有限实例：没有证明任意低质照片、复杂群像或所有名画都能自动获得同等美术质量。图像生成底稿需要审美复核；颜色/边缘分层有时需按图调整。多人共处是固定透明绘画面与真实相机透视，不是从原照片恢复真实三维人体。

从参考视频可观察到彩色笔触、主体放大、上一主体留下碎线时下一主体逐渐出现；不能由成片推断原作者用过特定三维软件。本 Skill 复用的是视觉规律和实际做过的实现，并非原工程逆向复制。

## 用户反馈后的 V3

用户否定了 V2 的轮播感、慢节奏和程序配乐。V3 默认人物段从 6.4 秒减至 3.5 秒，布局改为正交折返；加入近景穿层、拐角同时可见两个主体、非匀速 Hermite 镜头及短快门模糊。五人示例约 18.84 秒，配乐更换为曲库《快速组装》，通过实际音频低频峰定位到达点。技术验证和新输入测试见工程 V3 报告；用户随后明确评价 V3 效果“非常好”“基本上已经挺不错”，并要求扩展多猫版；因此 V3 的快速空间运镜已获用户认可。此认可不延伸为任意输入都能自动复制相同质量。

## 五猫实例

五种不同猫咪（虎斑、橘猫、暹罗、英短、奶牛猫）使用独立底稿、768 像素动物分层和可配置场景，保留 18.84 秒节奏。镜头关注眼睛/爪子/耳朵，画面内加入固定三维细毛线，最后回到完整打哈欠表情。四张底稿为本轮新生成，虎斑复用先前猫研究。猫版是第二个实际影片实例。用户随后反馈完整重叠时间偏短；修订版为每只猫增加 1.2 秒的校准视点停留，压缩其后穿层段，保持 18.84 秒与音乐到达点。修订版的主观认可仍需用户观看判断。

动物模式修正了把大量细毛拆成特征层导致缩小时透明碎点的问题；它仍是颜色和边缘启发式，尚未证明复杂实拍背景或所有宠物种类都能无需调整。


## 多种转场实验

用户进一步要求翻转、纵深、正交、放大和淡化，并希望一次比较多支视频。因此增加 fold / dive / cube / bloom 四种可选方案，沿用五猫底稿、18.84 秒音乐结构及 1.2 秒完整停留。折页、纵深和聚合模式可移动绘画面或调整透明度；正交房间保持绘画位置固定。交付四支影片和同步四宫格后，用户评价“总体挺不错的”，并要求将人物与猫咪合片；这是整体效果认可，不代表逐个方案的每帧均被审校。两张猫的独立 starter 输入通过全部四模式，原已认可的默认人物路径仍有六帧像素一致证据。

## 配音合片

人物与猫咪已合为约 40.93 秒的竖屏视频，包含简短输入/底稿对照、字幕与连续配乐。猫咪段在完整对齐时切换 dive、fold、bloom，保留 1.2 秒阅读停留。用户否定冰糖声音，试听后认可茉莉与白桦并选择白桦版本。配音应先试听再合成成片；该次声音偏好不等于所有用户的默认音色。
